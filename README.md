## 📖 About

This repository documents hands-on laboratory exercises completed during the **Basic Control & Industrial Automation Training** provided by **HA Consulting Group**. The repository covers relay-based control systems, PLC programming across multiple platforms, motor drive configuration, electrical design, and industrial automation simulations.

## 📚 Training Modules

| Category | Platform | Tasks |
|---|---|---|
| Classic Control (hands-on lab) | Relay logic / lab panels | 15 |
| PLC Programming — Siemens | TIA Portal | 20 |
| PLC Programming — Schneider | Schneider PLC | 1 |
| PLC Programming — Wecon | Wecon PLC | 1 |
| PLC Programming — KINCO | KINCO PLC | 1 |
